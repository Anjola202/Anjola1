# Maya: personal portfolio

## Your challenge

Recreate a designer portfolio with a navigation bar, split introduction and portrait, three project cards, an about section, skill labels, and a contact footer.
Match the supplied screenshots as closely as you can using your own HTML and CSS.
There are no lesson checkpoints or starter solution files in the student pack.

## References and assets

- `screenshots/desktop.png`: full-page reference captured at 1440 pixels wide.
- `screenshots/mobile.png`: full-page reference captured at 390 pixels wide.
- `images/`: the original image you need. Use a relative file path.
- `CONTENT.txt`: page copy, so you do not have to transcribe the screenshots.

**Fonts:** DM Sans (400, 500, 600, 700). Arial is the fallback.
Load the fonts from Google Fonts. The page must remain readable if they cannot load.

**Palette:** #fdfcf9 background; #242333 text; #7051c1 purple; #e9e2f4 lilac; #f4dfcf peach; #dfebdf green.

The project covers are made with HTML text and CSS background colours. The only image needed is images/portrait.png. Navigation links should jump to work, about, and contact. The contact address is fictional plain text.

## Requirements

- Use only HTML and CSS. No JavaScript, frameworks, or screenshot-as-background shortcut.
- Recreate the layout, spacing, type sizes, image crops, colours, borders, and rounded corners.
- Make the layout adapt to a phone screen without horizontal scrolling.
- Use meaningful headings, navigation, descriptive image alt text, and visible link focus styles.
- Keep the images local so they still work offline.

## Submit

Submit `index.html`, `style.css`, your `images` folder, and your own desktop and
phone screenshots. Open the page directly in a browser to check it. Your teacher
will compare visual accuracy, responsiveness, HTML structure, and readable CSS.
